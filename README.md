# Road Accident Analysis Dashboard (Excel Project)

## Project Overview
This project analyzes road accident data using Microsoft Excel to identify accident patterns, causes, and trends. The dashboard helps visualize accident frequency based on different conditions like time, location, vehicle type, and severity.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning
- Dashboard Design

## Features
- Accident analysis by year and month
- Severity level analysis
- Vehicle type comparison
- Location-based accident insights
- Interactive dashboard using slicers

## Purpose of the Project
The goal of this project is to analyze road accident data and provide insights that can help improve road safety and decision making.

## Outcome
Created an interactive Excel dashboard to visualize accident trends and identify major risk factors contributing to road accidents.
